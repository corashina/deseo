# CLAUDE.md

## Writing rules

Apply the stop-slop skill (`.claude/skills/stop-slop/SKILL.md`) to every piece of prose in this project: README and docs, code comments, commit messages, pull request titles and descriptions, issue comments, error messages, UI text, and replies to people.

Read the skill before you write prose, and check your draft against its rules before you deliver it. Keep code, commands, paths, and quoted text unchanged.

The skill's source and license live in `.claude/skills/SOURCES.md`.
