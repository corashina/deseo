# CLAUDE.md

## Writing rules

Apply three writing skills to every piece of prose in this project: README and docs, code comments, commit messages, pull request titles and descriptions, issue comments, error messages, UI text, and replies to people.

1. `.claude/skills/writing-clearly-and-concisely/SKILL.md` for grammar and composition (Strunk's rules).
2. `.claude/skills/stop-slop/SKILL.md` to cut filler phrases and formulaic structures.
3. `.claude/skills/humanizer/SKILL.md` for a final pass against AI writing patterns.

Read each skill before you write prose, and check the draft against all three before you deliver it. Where they disagree, stop-slop and humanizer win over Strunk on AI tells, and humanizer's "When not to act" section wins over both. Keep code, commands, paths, and quoted text unchanged.

Upstream sources and licenses live in `.claude/skills/SOURCES.md`.
